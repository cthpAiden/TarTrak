CHAPTER 1

Introduction

Section I. General

1-1.

Scope. This manual tells the operator how to put themselves and their squad on a map of the raid, what each control does, and everything the program reads from the computer.

1-2.

Equipment description. TarTrak is a free squad map for Escape from Tarkov. Each time you take a screenshot in raid, it puts your position and heading on an interactive map. Teammates in the same room appear on the same map. Quests, extracts, bosses and loot are drawn, with a filter for each.

It runs as an overlay on top of the game in borderless windowed mode, as a round minimap with a compass bezel or as a box.

the position is in the filename. that's the whole trick

Section II. What the program reads

CAUTION

TarTrak never touches the game process. It reads three things:

  1. The filenames of the screenshots the game saves. It can delete those screenshots afterwards, and only the ones named with coordinates.
  2. The game's text log, to learn which map you loaded.
  3. Whether your mark-here key is held down, using the same Windows call push-to-talk apps use.

It does not do any of the following:

  • Read memory
  • Inject code
  • Hook the keyboard
  • Send keystrokes
  • Accounts
  • Telemetry

The author cannot speak for Battlestate's anti-cheat. The list above is everything TarTrak does.

CHAPTER 2

Operating instructions

Section I. Setup

2-1.

Installation.

  1. a.Download the installer from the latest release and run it.
  2. b.Set Tarkov to borderless windowed.
  3. c.In raid, press PrintScreen. Your marker shows up on the map.

NOTE TarTrak asks for administrator rights because the game runs as administrator too. Without them, Windows hides the game's key state and the mark-here key only works after an Alt+Tab.

Table 2-1. Controls and indicators.
ControlFunction
F5Switch overlay mode.
F6Change overlay opacity.
F7Hide the window until you press it again.
Alt + dragMove the overlay.
Left Alt + PrtScDrop a private marker where you stand.

Section II. Squad operations

2-2.

Forming a room.

  1. a.One player clicks Create and shares the six-character code.
  2. b.Everyone else types it in and clicks Join.
  3. c.Positions go through a small relay server that keeps nothing and logs nothing. You can run your own.
