# Bundled tarkov.dev snapshot

`tasks.json`, `maps.json`, `meta.json` are generated by `npm run snapshot`
(`node --experimental-strip-types scripts/snapshot.ts`) from the static files at
`https://json.tarkov.dev/regular/` (regular game mode): `maps`, `maps_en`, `tasks`,
`tasks_en`, `traders`, `traders_en`. The script runs the same `jsonSource.ts` adapter the app
uses, so the files hold `QuestTask[]` and `MapInfo[]` already translated into English.
They are the offline fallback for the first run. Regenerate before each release.
If the files are missing, the app still works and fetches live data.
