### Task 12: Classify spawns exactly like tarkov.dev, add Stationary Guns

**Files:** `src/lib/layers/points.ts` (+test), `src/lib/layers/pointLayer.ts` (+test), `src/lib/map/map.css`.

Spawn rule, mirrored from tarkov.dev (tdmap.jsx lines 1250-1305), evaluated in this order:
1. `categories` has `boss`: bosses = map bosses whose `spawnKeys` include `spawn.zoneName`, deduplicated by `normalizedName`. If none: category `scav` when `categories` has `bot` and `sides` has `scav`, else SKIP the spawn. If exactly one boss and its normalizedName is one of `cultist-priest`, `rogue`, `black-div`, `af`, `bloodhound`: category = that normalizedName, name = boss name. Else category `boss`, name = bosses joined `", "` as `"Reshala (60%)"` (chance = `Math.round(spawnChance * 100)`).
2. else `categories` has `player`: category `pmc` when `sides` has `pmc` or `all`, else SKIP. Name `"PMC spawn"`.
3. else `categories` has `sniper`: category `sniper`, name `"Sniper Scav"`.
4. else `sides` has `scav` and `categories` has `bot` or `all`: category `scav`, name `"Scav spawn"`.
5. else SKIP.

### Task 13: Show only markers on the active floor

**Files:** `src/lib/map/mapsData.ts` (+test), `src/App.svelte`, `src/lib/map/MapView.svelte` (labels), `README.md`.

Rule, mirrored from tarkov.dev `markerIsOnLayer` / `markerIsOnActiveLayer` (tdmap.jsx 137-190), simplified to our single-active-floor model:
```ts
export type Containment = "full" | "partial" | false;
/** How a vertical span [bottom, top] at (x, z) relates to one floor layer's extents. */
export function onLayer(layer: MapLayer, x: number, z: number, top: number, bottom: number): Containment;
/**
 * activeFloor: null = base level. A marker is hidden when it is fully inside a bounded extent of
 * any non-active layer; otherwise shown when it is on the active layer, or (base level) when
 * it lies within def.heightRange (or heightRange is unset) and is not on any layer with extents.
 */
export function visibleOnFloor(def: MapDef, activeFloor: string | null, x: number, z: number, y: number, top = y, bottom = y): boolean;
```
`onLayer`: no extents -> `"partial"` is wrong; return `false` only when the layer has extents and none match; a layer without `extents` never claims a marker (return `false`). For each extent: match when `top >= height[0] && bottom < height[1]`; containment `"full"` when also `bottom >= height[0] && top <= height[1]`; when `extent.bounds` exists, the point must be inside one of them (reuse the existing `inBounds`).

Apply in `App.svelte`: `points` and `questMarkers` additionally filtered with `visibleOnFloor(def, activeFloor, p.x, p.z, p.y)`. The active floor is currently computed inside MapView (`activeFloor` derived from `pinnedFloor` and `app.ownPos`); lift that derivation into App.svelte (export `floorForHeight` already exists) and pass `activeFloor` down as a prop instead of `pinnedFloor`... keep `pinnedFloor`/`onFloorPinned` for the floor bar, add `activeFloor` prop. Labels: in MapView filter `d.labels` with `visibleOnFloor(d, activeFloor, x, z, y, top ?? 1000, bottom ?? -1000)` where `y = top !== undefined && bottom !== undefined ? (top - bottom) / 2 + bottom : 0` (tarkov.dev 1109-1130).

Counts stay per map (not per floor); README gets one sentence: "The filter counts are for the whole map; the map itself shows only markers on the selected floor."

Tests: streets 2nd-floor point hidden on ground and shown on "2nd Floor"; ground point hidden on "2nd Floor"; customs dorms point at y=4 inside bounds hidden on ground, far-away y=4 point shown on ground; a map with no layers shows everything; `heightRange` excludes a point below it on base level. Commit: `Show only markers on the active floor`.
