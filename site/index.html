How it works

Tarkov already writes your position down. TarTrak reads it.

1

Install

Download the installer from the latest release and run it. It needs Windows 10 or 11.

2

Borderless windowed

Set the game to borderless windowed so the overlay can sit on top of it.

3

Press PrtSc in raid

Your marker lands on the map with the way you are facing. Every screenshot moves it. TarTrak finds the map from the game's log.

The details

What each part does.

Shared screenshot

  • Take screenshots with the game's key as usual, then press F8 to send the last one to your room.
  • It pops up in a small window over the game, wherever each teammate placed it. Click to enlarge.
  • It closes after 10 s, and stays while the mouse is on it. The window never takes focus from the game.
  • Only that one picture, never a live stream. The relay passes it on and stores nothing.

Squad

  • One player clicks Create and shares the code. You see each other's position, heading and floor, plus shared markers, routes and live drawings.
  • Up to 12 players per room. A Hide button keeps the code off your stream.
  • The relay keeps nothing and logs nothing. You can run your own.
  • Markers never vanish. A teammate who goes quiet stays on the map, slowly dimming to 35%.

Raid replay

  • TarTrak records every raid you take a screenshot in: your positions and your squad's. Pick one of your last 10 in the Raids tab.
  • Every player's trail in their colour, bright for the last 3 minutes.
  • Play at 1× to 64×, or step from one screenshot to the next. Drag the timeline to jump anywhere.
  • A card counts your screenshots, how often you took one, and your longest gap.

Is it safe?

It never touches the game process.

Here is the complete list of what TarTrak reads, and what it does not do.

Reads

  • Screenshots the game savesThe filename holds your coordinates and rotation. The picture itself is only read when you press F8 to share it. By default TarTrak deletes the screenshots named with coordinates once read.
  • The game's text logTo learn which map you loaded, your screenshot key, and the raid clock.
  • Whether your mark-here key is heldThe same Windows call push-to-talk apps use.

Never

  • Reads game memory
  • Injects code
  • Installs keyboard hooks
  • Sends keystrokes to the game
  • Accounts or telemetry

FAQ

Questions people ask

Can this get me banned?

TarTrak never touches the game process. It reads the screenshots the game saves, the game's text log, and whether your mark-here key is held down, using the same Windows call push-to-talk apps use. It doesn't read memory, inject code, install keyboard hooks or send keystrokes to the game.

Nobody outside Battlestate can promise how their anti-cheat behaves, but that list is everything TarTrak does, and the source is public so you can check.

Windows says the installer is from an unknown publisher.

The installer isn't code-signed yet; a signing certificate costs money every year. SmartScreen shows "Windows protected your PC": click More info, then Run anyway.

Every release is built by GitHub Actions from the public source, so you can see exactly what went into it.

Why does it ask for administrator rights?

Because the game runs as administrator too. Without the same rights, Windows hides the game's key state from TarTrak, and the mark-here key only works after an Alt+Tab.

Does F8 share my whole screen?

No. It sends one picture: the last screenshot the game saved, and only when you press F8. There is no live stream. The relay passes it to your room and stores nothing.

Is it really free?

Yes. It's open source under GPL-3.0, with no accounts, no ads and no paid tier. If it helps your raids you can chip in on PayPal; tips go toward keeping the map working after each patch.

Do my teammates need it too?

Yes. Each player's position comes from their own screenshots, so everyone who wants to show up on the map runs TarTrak and joins the same room.

I rebound the screenshot key. Does it still work?

Yes. The game lists its key bindings in its log when it starts, and TarTrak reads your screenshot key from there. Settings shows the key it found.

Does it work in PvE?

Yes. Settings > Game mode switches the map and quest data between PvP and PvE.

Mac or Linux?

No. TarTrak runs on Windows 10 and 11, alongside the game.
