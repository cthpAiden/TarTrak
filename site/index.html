Setup

Three steps to your first marker.

  1. 1

    Install

    Download the installer from the latest release and run it. It needs Windows 10 or 11.

    Get v0.14.5
  2. 2

    Borderless windowed

    Set the game's screen mode to borderless windowed, so the overlay can sit on top of it.

  3. 3

    Press PrtSc in raid

    Your marker shows up on the map with your heading. Each screenshot moves it. TarTrak finds the map from the game's log.

Why it asks for administrator rights. The game runs as administrator too. Without them, Windows hides the game's key state from TarTrak and the mark-here key only works after an Alt+Tab.

FAQ

Questions people ask

Can this get me banned?

TarTrak never touches the game process. It reads the filenames of the screenshots the game saves, the game's text log, and whether your mark-here key is held down, using the same Windows call push-to-talk apps use. It doesn't read memory, inject code, install keyboard hooks or send keystrokes to the game.

Nobody outside Battlestate can promise how their anti-cheat behaves, but that list is everything TarTrak does, and the source is public so you can check.

Why does it ask for administrator rights?

Because the game runs as administrator too. Without the same rights, Windows hides the game's key state from TarTrak, and the mark-here key only works after an Alt+Tab.

Is it really free?

Yes. It's MIT licensed, with no accounts, no ads and no paid tier. If it helps your raids you can chip in on PayPal; tips go toward keeping the map working after each patch.

Do my teammates need it too?

Yes. Each player's position comes from their own screenshots, so everyone who wants to show up on the map runs TarTrak and joins the same room.

Will it fill up my screenshots folder?

No. By default it deletes the screenshots named with coordinates once it has read them, and only those. Turn that off in Settings if you want to keep them.

I rebound the screenshot key. Does it still work?

Yes. The game lists its key bindings in its log when it starts, and TarTrak reads your screenshot key from there. Settings shows the key it found.

Does it work in PvE?

Yes. Settings > Game mode switches the map and quest data between PvP and PvE.

Mac or Linux?

No. TarTrak runs on Windows 10 and 11, alongside the game.
